# 高阶优化清单（C 端大流量 / 微前端 / SSR 才启用）

主清单是工业标准必做项；本清单属于高阶、高成本、面向大流量场景的增强项。
启用条件见 `decision-matrix.md §3`：后台管理/内部系统**不启用**（投入产出比低）；公网 C 端按流量层级部分或全量启用。

---

## 一、关键渲染进阶

- CLS 专项：图片预先设置宽高、预留容器空间，防止加载撑开布局偏移
- LCP 元素优先预加载：最大内容绘制元素作为最高优先级资源
- 避免长任务：用 `isInputPending` 判断主线程是否空闲再执行非紧急逻辑
- 图片渐进式加载：低清占位图 LQIP、SVG 占位
- 响应式图片：`srcset + sizes`，按设备分辨率下发不同尺寸，手机不加载超大图

## 二、打包进阶

- 模块预构建（Vite 预构建 / webpack DllPlugin），减少重复第三方包解析
- 打包产物分析：webpack-bundle-analyzer / rollup-plugin-visualizer 定期定位体积异常依赖
- 模块联邦 Module Federation（微前端场景）：跨应用共享依赖，避免重复加载同一库
- 国际化多语言剥离：按需打包语言包，不一次性打包全部语言

## 三、网络传输进阶

- HTTP/2 或 HTTP/3（QUIC），配合 CDN 启用多路复用
- 0-RTT TLS 握手优化（CDN 侧配置）
- 资源优先级：`fetchpriority` 属性控制加载优先级，优先首屏资源
- 连接池复用管理

## 四、预加载策略精细化管控

- 滥用 preload 会抢占带宽拖慢首屏：preload 仅限当前页关键资源，数量 ≤ 5
- prefetch 仅用于用户高概率下一跳，空闲时加载
- CI 中审查首屏资源瀑布图，防止预加载膨胀

## 五、微前端专属优化（仅微前端架构）

- 子应用资源缓存
- 子应用沙箱内存隔离，防止全局变量污染
- 子应用懒加载，不一次性加载全部子应用
- CSS 沙箱隔离，样式互不污染

## 六、用户体验高阶

- TTI（可交互时间）专项优化
- 懒 hydration（按需注水）：SSR/SSG 场景不一次性 hydrate 全部组件
- SSR / SSG：C 端首页极大优化首屏
- 骨架屏动态生成，而不是手写固定骨架

## 七、性能压测专项

- Lighthouse 持续 CI 自动化打分，低于阈值阻断发布
- 模拟弱网（3G）上线验收
- 模拟低配手机 / 低配浏览器性能测试（低端机型卡顿专项验证）

## 八、细分安全项（金融等高安全级别项目）

- 子资源完整性 SRI `integrity`，校验 CDN 返回 JS 是否被篡改
- 安全响应头全套：X-Content-Type-Options、X-Frame-Options、X-XSS-Protection
- 防止 JSON 劫持
- 敏感页面防截屏（Web 层面有限方案，注明局限性）

## 九、国际化专项

- 语言包懒加载
- 翻译文本抽离，不硬编码在业务代码

## 十、极端边界场景

- 标签页后台休眠降级：`document.visibilityState`，切后台减少主线程消耗（定时器/轮询降频）
- 电量感知 API：低电量时关闭非核心动画、轮询（移动端省电）
- 网络状态监听 `navigator.onLine`：动态切换轮询策略，断网停止轮询请求

## 选用建议

| 项目 | 启用范围 |
| --- | --- |
| 后台管理 / 内部系统 | 不启用 |
| 公网 C 端常规 | 一、二、三、四 |
| 公网 C 端高流量 | 全量 |
| 微前端 | + 五 |
| SSR/SSG | + 六 |
| 金融级安全 | + 八 |
