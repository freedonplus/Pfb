# 生产级前端主清单（所有项目必过）

面向生产、大型项目、高并发用户场景的工业标准必做清单，十大板块。
用途：阶段 2 撰写方案时逐项查漏；审核时逐条判定。
标注：[P0] 阻断上线 / [P1] 强烈建议 / [P2] 增强项。

---

## 一、构建 & 打包阶段优化

### 1. 产物体积
- [P0] 生产打包模式，关闭开发环境代码、移除 debugger / console.log
- [P0] Tree-Shaking（ESM 模块；避免 commonjs 阻碍 tree-shake）
- [P0] 代码分割 Code Split + 路由级懒加载
- [P1] 第三方依赖单独抽离 vendor chunk
- [P1] 超大组件/弹窗组件异步引入
- [P0] UI 组件库按需引入，禁止全量导入
- [P1] 替换重型库为轻量替代品（moment → dayjs 等）
- [P1] 移除未使用的 npm 包
- [P1] JS / CSS 压缩，去除注释空格
- [P1] CSS Modules / scoped 样式隔离，防止全局污染；避免超大全局 CSS
- [P0] 资源文件名内容 hash，支撑长效缓存
- [P0] sourceMap 线上不部署，单独归档用于线下排查，防止源码泄露

### 2. 静态资源
- [P1] 图片自动化压缩
- [P1] 多格式图片兼容 webp / avif 降级 jpg/png
- [P2] 字体文件子集化，删减无用字符
- [P2] 字体文件预加载策略

### 3. 构建速度（CI 流水线）
- [P1] 构建缓存，提升 CI 打包速度
- [P2] 大文件排除、忽略不需要打包的目录
- [P2] 多线程打包

## 二、浏览器资源加载优化（首屏性能重点）

### 1. 资源预策略
- [P1] preconnect 预连接后端接口域名、CDN 域名
- [P2] prefetch 预加载未来页面资源（非首屏、用户大概率访问）
- [P1] preload 预加载当前页关键资源（关键 JS、字体）；**数量受限，见 decision-matrix §8**

### 2. 缓存策略（Nginx + 前端配合）
- [P0] index.html 禁止强缓存 / max-age=0，保证发布更新用户拿到新页面
- [P0] 带 hash 的 JS / CSS / 图片 / 字体设置长期缓存 max-age=31536000
- [P1] 合理使用 Cache-Control + ETag

### 3. 传输压缩
- [P1] Nginx 开启 Gzip / Brotli

### 4. CDN
- [P1] 静态资源全部托管 CDN
- [P2] CDN 域名拆分，突破同域名并发限制
- [P1] CDN 缓存刷新策略，版本更新自动刷新

### 5. 懒加载
- [P0] 图片懒加载（视口外）
- [P1] 视频懒加载
- [P1] 组件懒加载、弹窗懒加载

## 三、运行时渲染性能

### 1. DOM 渲染
- [P1] 减少一次性大批量 DOM 插入，批量更新
- [P1] 避免强制同步布局（循环读 offset/client 再改样式触发多次 reflow）
- [P0] 动画优先 transform / opacity（GPU 合成），避开 top/left/width 动画
- [P1] 减少 DOM 节点总数，删除无用隐藏节点

### 2. 长列表大数据
- [P0] 优先分页
- [P0] 超大数据表：虚拟滚动，仅渲染可视区域
- [P0] v-for / map 必须用正确 key，禁止无脑 index 作 key

### 3. 框架层面
- [P1] Vue3：v-if / v-show 合理选择；大对象用 shallowRef/shallowReactive；v-once 静态内容
- [P1] React：memo、useMemo、useCallback 合理使用，避免不必要重渲染

### 4. 主线程阻塞
- [P1] 大量循环/复杂计算放 Web Worker
- [P1] 分片渲染：requestIdleCallback 空闲时批量渲染

## 四、请求层优化 & 业务防错（最容易产生线上 bug）

- [P0] 按钮防重复提交：提交锁 loading，接口结束才解锁
- [P0] 搜索框防抖 debounce；滚动/resize 节流 throttle
- [P0] AbortController：页面跳转取消未完成请求，防旧响应覆盖
- [P1] 限制最大并发请求数量 + 请求队列管理
- [P1] 统一接口超时时间
- [P0] 幂等接口才允许自动重试；新增提交、支付类接口禁止自动重试
- [P1] 只读查询接口本地短缓存 + 缓存失效机制
- [P1] 表单提交携带前端生成唯一 requestId，辅助后端幂等
- [P0] 统一异常封装：401 跳登录、token 无感刷新、统一错误提示（不抛原始堆栈给用户）

## 五、内存泄漏治理（页面挂一整天必现）

- [P0] setInterval / setTimeout 组件销毁必须清除
- [P0] addEventListener 组件销毁 removeEventListener
- [P0] window 全局事件（resize/scroll/keydown）页面离开注销
- [P0] 第三方实例销毁：ECharts / 地图 / 播放器组件销毁时 destroy
- [P1] 避免全局变量持续追加大数组/大对象
- [P1] 事件总线订阅组件离开取消订阅
- [P1] 闭包引用大对象导致无法 GC 的排查

## 六、交互体验 & 业务健壮性

- [P1] 骨架屏，提升首屏加载感知
- [P1] 加载中状态
- [P0] 空状态兜底页面，列表无数据友好提示，禁止空白
- [P0] 异常兜底页面（全局错误边界）
- [P1] 大文件上传：分片 + 断点续传 + 进度展示
- [P1] 输入框实时校验，提前拦截非法请求
- [P0] 高危操作二次确认弹窗（删除、批量删除）
- [P1] 新版本发布提示用户刷新获取最新资源
- [P2] 离线兜底（PWA 可选）、弱网提示

## 七、前端安全（企业硬性要求）

- [P0] HTTPS 全站强制跳转
- [P1] CSP 内容安全策略，防御 XSS
- [P0] XSS 防护：输出转义；v-html / dangerouslySetInnerHTML 必须白名单过滤
- [P1] Cookie 配置 HttpOnly + Secure + SameSite
- [P0] Token 存放策略：优先请求头，禁止放 URL 参数
- [P1] 防点击劫持（X-Frame-Options / frame-ancestors）
- [P2] 资源防盗链
- [P0] 敏感信息禁止控制台打印
- [P1] Nginx 关闭 autoindex 防目录浏览
- [P1] 输入过滤、特殊字符校验

## 八、监控、告警、容灾

- [P1] JS 全局异常捕获 window.onerror / unhandledrejection
- [P1] 资源加载失败监控上报
- [P2] 用户行为埋点
- [P1] 性能监控：LCP / FID(INP) / CLS / 首屏与接口耗时
- [P1] 错误率超阈值告警
- [P1] 线上异常日志上报，附带用户环境与浏览器信息
- [P1] 降级策略：重要模块加载失败有兜底，非核心资源失败不阻塞主流程

## 九、工程化 & CI/CD & 版本治理

- [P0] 发布携带版本号标识
- [P0] 发布前 ESLint + Prettier + TS 类型校验
- [P1] 关键业务单元测试 / 组件测试
- [P0] 预发布环境验证后再上生产
- [P1] 静态资源版本管理，支持快速回滚
- [P1] 灰度发布：小流量先更新观察报错率
- [P0] 禁止直接在生产环境改代码，一切走流水线

## 十、兼容性 & 健壮性

- [P1] 定义目标浏览器兼容列表（browserslist）
- [P1] polyfill 按需引入，不全量引入
- [P1] 移动端 / PC 大屏适配方案
- [P2] 屏幕缩放、异常尺寸下布局容错
- [P1] 弱网环境测试

## 十一、代码架构层面（长期维护）

- [P1] 模块拆分、职责解耦
- [P1] 全局状态管理避免存巨量无用数据
- [P1] 组件复用，抽离公共业务组件
- [P1] 样式隔离，避免全局样式互相覆盖
- [P1] 统一接口管理，集中管理 api 地址
- [P1] 常量单独抽离，硬编码改常量配置

---

## 上线优先级排序（先做高风险项）

1. 请求层：防重复提交 + 请求取消 + token 无感刷新
2. 内存泄漏：定时器、事件、第三方实例销毁
3. 资源缓存策略：index.html 不做强缓存
4. 首屏包体积：路由懒加载、按需引入组件库
5. 安全基础：HTTPS、XSS 基础防护
6. 异常监控接入，线上 bug 及时感知
7. 长列表虚拟滚动 / 分页防止 DOM 过多卡顿
8. 动画渲染优化避免页面掉帧
